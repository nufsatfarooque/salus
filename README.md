# Salus

Support service platform for autistic and disabled children in Bangladesh.

## Structure
- /frontend — Next.js app (TypeScript, Tailwind, shadcn/ui)
- /backend — Node.js/Express API (TypeScript)

## Running Locally

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

Frontend runs on http://localhost:3000
Backend runs on http://localhost:5000
